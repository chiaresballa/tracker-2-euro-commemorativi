# Tracker 2 Euro Commemorativi

Catalogo interattivo delle monete da 2 euro commemorative emesse dai paesi dell'area euro e dalle emissioni comuni, dal 2004 al 2026.

## Funzionalità

- 615 monete censite, con immagine, paese, anno e titolo dell'emissione
- Filtri per anno, paese e tipologia (nazionale / comune europea)
- Ricerca testuale
- Checkbox per segnare le monete possedute, con statistiche live
- Persistenza locale (salvataggio nel browser) ed esportazione/importazione della collezione in JSON
- Pagina singola e completamente autonoma (nessuna dipendenza esterna): tutte le immagini sono incorporate direttamente nel file HTML

## Utilizzo

Apri `index.html` in un browser, oppure visita la versione pubblicata su GitHub Pages (link nella sezione "About" del repository).

## Fonte dati

Le informazioni sulle monete e le relative immagini provengono da [ucoin.net](https://en.ucoin.net).
